Phone pairing v2

2. Session lifetime

Paired phones keep a session token in the Keychain. Tokens never expire; the Mac revokes them explicitly from Settings → Phones. This keeps the phone usable after weeks offline.

Reconnects are ranked by Tailscale CGNAT first, then Bonjour, so an off-LAN phone still finds the Mac. CommentQuestionMust changeReplaceDeleteHighlight✦ Ask ①

3. Revocation

②Proposed editfrom thread “Why do tokens never expire?” · on Refine 2Edit…✗ Reject✓ Accept
Tokens never expire; the Mac revokes them explicitly from Settings → Phones. Tokens expire after 30 days without a connection, and the phone re-pairs with a 6-digit code. The Mac can also revoke a phone at any time from Settings → Phones.

Revoking a phone removes its key from controllers.json and closes any live socket within one second.

4. Failure modes

If the exchange fails, for example from a mistyped code, the phone shows the code entry again and the pairing window stays open until it times out.

  1. ✦ Ask is a new button at the end of the selection toolbar. It opens the thread panel on a new thread anchored to the selection, with the composer focused. Pressing ✦ Ask with nothing selected starts a thread on the whole plan.
  2. Diffs render inline in the plan at their target, showing what's removed and what's added. You can accept, reject, or Edit…, which opens the new text for you to adjust before accepting. Accepting sends applyThreadDiff, which becomes a new user-edited version, the same as a hand edit. Diffs also appear inside the thread, linked to the inline copy.
  3. Threads (4) ⤢ in the rail header opens the wide panel. Opening a card opens the panel on that thread.
  4. Stale: the round rewrote the target, and the diff could not be rebased with EditLayer.retarget. It is never applied as a guess. Re-propose runs one turn against the current version.
  5. The index has three groups: Open (by section, in plan order), Needs you (threads where the agent asked you something, or has a diff waiting), and Resolved. Selecting a thread scrolls the plan to its anchor.
  6. The thread header has the agent/model menu (defaulting to the integrator's), the auto-accept toggle, and the version the thread is reading. A thread follows the newest version automatically when a round lands, and a divider in the thread marks the point where it moved.
  7. Structured questions appear inside the thread. They use the same component as triage, and the phone uses it too.
